# 학교 분실물 관리 웹사이트

이 프로젝트는 초보자가 따라 하면서 만들 수 있는 기본 분실물 관리 웹사이트입니다.

## 프로젝트 구조

- `index.html`: 메인 화면 구조
- `styles.css`: 디자인과 레이아웃
- `app.js`: 데이터 로딩, 검색, 등록 기능

## 실행 방법

1. 이 폴더를 컴퓨터에서 열기
2. `index.html` 파일을 브라우저로 열기
3. 브라우저에서 페이지가 보이면 완료

## QR 코드로 교무실 자동 선택

교무실별 QR 코드를 만들 때는 URL 뒤에 교무실 이름을 붙이면 됩니다.

예시:

- `index.html?room=교무실 1`
- `index.html?room=교무실 2`

이렇게 접속하면 등록 폼에서 보관 교무실이 자동으로 선택됩니다.
